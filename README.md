# Xavier's family

App familiar (agenda, feines, compra, menú setmanal i fotos del Xavier).
Funciona amb el compte de Google: el calendari i les fotos són al Google Calendar i al Drive familiar,
i les feines, la compra i el menú en un full de càlcul del Drive.

Per instal·lar-la al mòbil: obre l'adreça a Safari (iPhone) o Chrome (Android) i tria «Afegir a la pantalla d'inici».
